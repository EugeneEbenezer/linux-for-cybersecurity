# linux-for-cybersecurity

 Linux Commands for Cybersecurity:

 Overview:
Basic Linux commands useful for cybersecurity and ethical hacking.

 Commands:

File Operations:
- ls → list files
- cd → change directory
- cp → copy files
- rm → remove files

 Networking:
- ifconfig
- netstat
- ping

 Learning Outcome:
- Improved command-line skills
- Understood system navigation
